## 🧭 核心知识主线

```
线性化三条件 ──► 系统框图（开环 vs 闭环）
      │
      ▼
开环传递函数 T(s) = H(s) · Gc(s) · Gpwm(s) · Gvd(s)
      │              │        │          │
      │         误差放大器   PWM调制器   开关变换器
      │         (3种补偿)   (1/Vm)     (含RHP零点)
      ▼
穿越频率 / 相位裕度 ──► 环路补偿设计
```

- **四级相乘**：$T(s)=H(s)\cdot G_c(s)\cdot G_{pwm}(s)\cdot G_{vd}(s)$
- **反激带宽受限根源**：Boost / Buck-boost / 反激均为间接传能，存在**右半平面零点（RHP 零点）**，穿越频率需远低于 $f_{RHP}=\dfrac{R(1-D)^2}{2\pi L}$
